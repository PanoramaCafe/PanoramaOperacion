PANORAMA CAFÉ — OPERACIÓN DIARIA V15.0

Correcciones principales
- Estado y detalles aislados por tipo de checklist y fecha.
- Migración automática desde almacenamiento local de versiones anteriores.
- Pendientes e incidencias generados desde tareas conservan la fecha del checklist.
- Cada checklist registrado conserva una fotografía de sus tareas.
- El borrador se elimina al finalizar correctamente el checklist.
- Restaurar lista inicial limpia borradores incompatibles sin borrar el historial.
- Eliminada la función duplicada de duración de gas.
- Reporte implementado: exporta CSV compatible con Excel.
- Texto de Alitas aclarado como acumulado histórico, no inventario.
- Manifest alineado con la identidad visual.
- Service Worker V15 usa solo recursos esenciales obligatorios para evitar fallos si faltan iconos.

Limitación vigente
La aplicación sigue siendo local por dispositivo/navegador. No sincroniza datos entre teléfonos o tablets.
